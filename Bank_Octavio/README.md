# 🏦 Sistema Bancário em Python (POO)

Este é um projeto de simulação bancária desenvolvido para praticar os pilares da **Programação Orientada a Objetos (POO)** e boas práticas de desenvolvimento em Python.

## 🚀 Funcionalidades
- **Gerenciamento de Contas:** Criação de conta corrente e poupança.
- **Operações:** Depósito, saque e transferência entre contas.
- **Interface Web:** Implementada com Flask.

## 🛠️ Tecnologias Utilizadas
- **Python 3.x**
- **Flask:** Interface web.
- **SQLite3:** Banco de dados relacional.
